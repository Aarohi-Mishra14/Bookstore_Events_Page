# Bookstore_Events_Page
A static events board for an independent bookstore, so floor staff can look up ongoing, upcoming and popular events instead of using paper logs and Excel sheets.

🔗 Live demo: https://bookstore-events-page.vercel.app

## Features
- Ongoing / Upcoming / Popular / All events tabs
- Search by title, author, host or location
- Category filter
- Add/edit events with form validation
- "No results" message for empty searches
- Loading and image fallback states for slow connections
- Keyboard and screen-reader accessible

## Tech
HTML, CSS, JavaScript — no frameworks, no build step. Icons from Font Awesome, fonts from Google Fonts (both via CDN).

## Notes
- Added/edited events are stored in memory only (reset on page refresh) — no backend yet.
- Built with some help from AI for code review, bug fixes and accessibility.
